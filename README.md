# ParkEase — Public Privacy Policy & Legal Webpage

This standalone repository contains the official, Google Play Store-compliant **Privacy Policy, Terms of Service, and User Data Deletion Instructions** for the **ParkEase Android App** (`com.parkease.app`).

---

## 🚀 How to Publish to Get Your Live HTTPS URL (Free & Instant)

Google Play Console requires a public HTTPS URL (e.g. `https://parkease-privacy.vercel.app`). Choose any of the 3 free methods below:

### Option 1: Netlify (Drag & Drop — No CLI Required)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this entire folder (`E:\APP PROJECT\ParkEase app privacy policy web`) into the browser.
3. Netlify will instantly give you a free live HTTPS URL: `https://something.netlify.app`.
4. (Optional) Go to Site Settings ➔ Change site name to `parkease-privacy.netlify.app`.

---

### Option 2: Vercel (1-Click CLI or GitHub)
1. Open PowerShell in this folder:
   ```powershell
   cd "E:\APP PROJECT\ParkEase app privacy policy web"
   npx vercel --prod
   ```
2. Press **Enter** to accept defaults.
3. Your live link will be printed: `https://parkease-privacy-policy.vercel.app`.

---

### Option 3: GitHub Pages
1. Push this folder to a GitHub repository (e.g., `github.com/shravanawala19/parkease-privacy`).
2. Go to **Settings ➔ Pages ➔ Source: main / root ➔ Save**.
3. Your live URL will be: `https://shravanawala19.github.io/parkease-privacy/`.

---

## 📋 What to Paste in Google Play Console
Once deployed, copy your live link and paste it into:
* **Google Play Console** ➔ **Policy & Programs** ➔ **App Content** ➔ **Privacy Policy** ➔ Paste your URL.
